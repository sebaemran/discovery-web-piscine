This Project Covers Linux Terminal Fundamentels, Git Version Colntrol And GitHub Workflows.

## Why Git Makes Development Easier
-Git Helps Protect Code By Keeping a History Of Changes and Making It Possible To Restore Earlier Versions When Needed.
-Get Tracks Changes To Files Through Commits, So Developers Can See What Changed And When.
-Git Makes Teamwork Easier By Allowing Multiple Developers To Work On The Same Project, Share Changes And Combine Their Work.

## Git Workflow
The Basic Workflow is: Edit, Add, Commit And Push.
